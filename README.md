# 🚀 AfriCredit - Alternative Data Credit Scoring Engine

![Status](https://img.shields.io/badge/Status-Prototype-green)
![License](https://img.shields.io/badge/License-MIT-blue)

AfriCredit ni mfumo wa Fintech unaotumia **Alternative Data (Data Mbadala)** kutoka kwa wasambazaji wa bidhaa na miamala ya simu ili kutengeneza **Digital Credit Score** kwa ajili ya wafanyabiashara wadogo na wa kati (SMEs) nchini Tanzania waliokosa sifa za kibenki.
